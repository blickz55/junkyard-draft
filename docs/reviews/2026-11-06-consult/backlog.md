# Consultant panel, 2026-11-06

The output of a 19-agent workflow (four readers over the docs, the code and the evaluations; two web researchers; four consultants, each a different angle; one skeptic per top proposal; one synthesis), run when the owner asked for incremental improvements toward a web and Steam release. Everything here was written by agents: it steers the work and is never quoted as what customers think. Numbers about the game were read from the tools by the readers; numbers about the field come with their sources or are marked as from memory.
